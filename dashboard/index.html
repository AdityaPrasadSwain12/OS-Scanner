⌁

Enroll this installation

A browser cannot silently install or control software on a device. After launching the downloaded package, use a short-lived, single-use enrollment grant to connect it to this server.

Copy this token now.It is displayed only in this tab, expires shortly, and can enroll one endpoint.
Developer portable enrollmentThe current EXE is a portable test build, not a silent managed installer. Copy and run this setup in an elevated PowerShell window. It verifies the EXE and configuration, then securely prompts you to copy and paste the one-time token before it enrolls and starts the agent.
